# 🎬 Cinema

Educational project — desktop cinema catalog application built with Java and a graphical user interface. Browse movies with posters and watch trailers.

## 🛠 Tech Stack

- Java
- Swing (GUI)

## ✨ Features

- Browse movie catalog with posters
- Watch movie trailers directly in the app
- Simple and intuitive interface

## 🎥 Movies in Catalog

- Minions II
- The Odyssey
- Spider-Man: Brand New Day

## 📂 Project Structure
Cinema/
├── src/
│ ├── Main.java # Application entry point
│ ├── CinemaGUI.java # Graphical user interface
│ └── Movie.java # Movie entity class
└── media/ # Posters (.jpg) and trailers (.mp4)

## 🚀 Getting Started

### Requirements
- Java JDK 8 or higher
- IntelliJ IDEA (recommended)

### How to Run
1. Clone the repository:
```bash
   git clone https://github.com/egorov-nikita/Cinema.git
```
2. Open the project in IntelliJ IDEA
3. Run `Main.java`
